# Agent 工具使用说明

本文档用于支持 RAG QA 和 LLM Tool Calling 的工具选择说明，帮助 Agent 判断用户意图、选择工具和生成参数。

## 1. 总体原则

当前 AI Pilot Agent 支持多类数据分析工具，包括渠道转化分析、股票风险收益分析、均线策略回测、参数扫描、图表生成和 Markdown 报告生成。

LLM 只负责理解用户意图、选择工具和生成参数；Python 负责文件类型检查、参数校验、工具执行、日志记录和 trace 展示。

如果用户输入不属于已有工具能力范围，Agent 应该说明当前没有合适工具，而不是强行调用工具。

## 2. 渠道转化数据工具

对于字段类似 date、channel、visits、signups、payments 的渠道转化数据，可以使用渠道分析工具。

适合任务包括：

- 读取 CSV 文件。
- 查看字段。
- 查看缺失值。
- 查看统计信息。
- 分析渠道转化率。
- 判断表现最好的渠道。
- 生成渠道分析报告。

当用户问“哪个渠道表现最好”“分析渠道转化率”“生成渠道分析报告”时，应选择渠道分析相关工具。

## 3. 股票风险收益工具

对于字段类似 date、close 的股票价格数据，可以使用金融分析工具。

适合任务包括：

- 计算总收益率。
- 计算年化波动率。
- 计算最大回撤。
- 计算夏普比率。
- 生成金融指标报告。

当用户问“分析风险收益”“生成金融指标报告”时，应选择金融指标相关工具。

## 4. 均线策略回测工具

对于字段类似 date、close 的股票价格数据，可以运行均线策略回测。

如果用户要求“运行 MA5-MA10 回测”，应优先选择 run_moving_average_backtest，并传入 short_window=5、long_window=10。

如果用户要求“生成 MA5-MA10 回测报告”，应优先选择 generate_backtest_report，并传入 short_window=5、long_window=10。

如果用户要求“生成 MA5-MA10 回测图表”，应优先选择 generate_backtest_charts，并传入 short_window=5、long_window=10。

## 5. 参数扫描工具

如果用户要求“扫描均线参数”，应选择 parameter_scan 相关工具。

如果用户要求“生成参数扫描报告”，应优先选择 generate_parameter_scan_report。

如果用户要求“生成参数扫描图表”，应优先选择 generate_parameter_scan_chart。

如果用户要求“生成策略研究总结报告”，应优先选择 generate_strategy_summary_report。

## 6. sort_by 参数映射规则

参数扫描和参数扫描图表通常需要 sort_by 参数。sort_by 用来决定按照哪个指标排序。

当用户说“收益率”“收益最高”“按收益排序”“总收益率”时，sort_by 应使用 strategy_total_return。

当用户说“夏普”“夏普比率”“风险调整收益”“单位波动收益”时，sort_by 应使用 sharpe_ratio。

当用户说“最大回撤”“回撤”“风险更小”“控制回撤”时，sort_by 应使用 max_drawdown。

如果用户问“如果用户问最大回撤，sort_by 应该是什么？”，回答应说明：sort_by 应该是 max_drawdown。

## 7. 文件类型保护原则

如果当前文件是渠道转化数据，不应该执行股票风险收益或均线回测工具。

如果当前文件是股票价格数据，不应该执行渠道转化分析工具。

当文件类型不匹配时，系统应该提示用户切换到合适的数据文件，而不是强行执行。

## 8. 知识问答与工具执行的区别

知识性问题应该走 RAG QA。例如：

- MA5-MA10 策略适合震荡行情吗？
- 最大回撤是什么意思？
- 夏普比率高说明什么？
- 如果用户问最大回撤，sort_by 应该是什么？

执行性任务应该走 Tool Calling。例如：

- 运行 MA5-MA10 回测。
- 生成 MA5-MA10 回测报告。
- 生成 MA5-MA10 回测图表。
- 按最大回撤生成参数扫描报告。
- 生成策略研究总结报告。
